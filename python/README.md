# UTOPAY API client — python

Client for the [UTOPAY payment gateway API](https://utopay.app/payment-gateway-api): cards, Apple Pay, PayPal and crypto (USDT, ETH, BNB) with payouts to your own wallet.

See the [main README](../README.md) for usage, and the full reference at **https://utopay.app/docs**.

- Website: https://utopay.app
- Crypto gateway: https://utopay.app/crypto
- CMS plugins: https://utopay.app/plugins
